휴대폰 브라우저에서 로그인하고 시나리오와 영상을 올리세요. 대사를 말한 순간에 자막이 놓입니다. 문구와 시간을 다듬고 완성 영상이나 자막 파일(SRT)을 받으세요.

  2. 자막 초안

한줄 스튜디오가 하는 일

  • 자막 문구는 대본에서

    대본 파일(PDF·텍스트·Word)에서 대사만 골라 자막 문구로 씁니다. 대사를 한 줄씩 다시 치지 않아도 됩니다.

  • 시간은 말소리에 맞춰

    영상에서 들리는 말을 대본과 맞춰 보고, 대사가 시작하고 끝나는 때에 자막을 놓습니다.

  • 인터뷰 쇼츠 만들기

    인터뷰 대본과 장면 클립을 넣으면 질문 자막, 구역 카드, 시작·마무리 화면을 넣어 세로 쇼츠로 만듭니다.

사용 순서

파일 두 개를 넣고 기다린 뒤, 표시된 몇 줄만 확인하면 됩니다.

  1. 대본과 영상 넣기

    '새 영상에 자막 달기'를 누르고 대본 파일과 자막 없는 완성 영상을 고릅니다. 대본 파일 대신 대사를 붙여 넣어도 됩니다. 원본 파일은 바꾸지 않습니다.

  2. 대사 알아듣고 시간 맞추기

    자동으로 진행되니 기다리면 됩니다. 4분 영상이 NVIDIA 그래픽카드 PC에서 약 20초, 그래픽카드 없이 CPU로는 약 1분 걸렸습니다(8코어 데스크톱 CPU 기준).

  3. 표시된 줄만 확인

    시간이 애매한 줄만 따로 표시됩니다. 그 부분을 재생해 보고, 맞으면 '맞아요'를 누르고 어긋나면 '조금 일찍'·'조금 늦게'로 옮깁니다.

  4. 영상으로 내보내기

    자막 모양 4가지 중 하나를 고르고, 필요하면 인트로·아웃트로·페이드를 넣어 영상(MP4)으로 내보냅니다. 다른 편집 프로그램에서 이어서 고치려면 자막 파일(SRT)로 내보냅니다.

자막 모양과 마무리

자막 모양 4가지(테두리, 그림자, 굵은 글꼴, 테두리+그림자)를 실제 장면에 미리 그려 놓고 눈으로 비교해 고릅니다. 글꼴은 본고딕(Noto Sans KR)입니다.

인트로·아웃트로
가지고 있는 인트로·아웃트로 영상을 등록하면 앞뒤에 붙입니다.
페이드
본편 시작과 끝이 1초 동안 서서히 밝아지고 어두워집니다.
장면 안내
대본에 적힌 '오후' 같은 시간·장소 안내를 화면에 넣습니다.
다른 화질로 바꾸기
자막을 맞춘 뒤 같은 영상의 다른 화질 파일(예: 4K)로 바꿔 내보낼 수 있습니다.

클립으로 인터뷰 쇼츠

인터뷰 대본 PDF와 인물별 장면 클립(짧은 영상 파일)을 넣으면 1080×1920 세로 쇼츠로 만듭니다. 편집 프로그램이 없어도 됩니다.

질문은 자막으로 넣고, 구역이 바뀔 때는 '#1: 그날 트레이너의 속마음' 같은 카드를 넣습니다.
앞 화면·끝 화면

Windows 설치판의 개인정보와 안전

설치판은 대사 인식과 자막 출력을 사용자 PC에서 처리합니다. 웹 편집기는 로그인한 회원이 올린 대본과 영상을 한줄 스튜디오 서버에서 처리합니다.

  • 영상·대본·자막은 보내지 않음

    작업 파일은 PC의 작업 폴더에만 저장됩니다.

  • 처음 실행할 때 내려받기

    대사를 알아듣는 데 쓰는 인식 모델(약 1.6GB)을 받습니다. NVIDIA 그래픽카드가 있으면 그래픽카드 부품(약 1.4GB)도 받습니다.

  • 전자 서명이 맞는 새 판만 적용

    실행할 때 새 판이 있는지 확인합니다. 전자 서명이 맞는 파일만 적용하고, 새 판이 켜지지 않으면 이전 판으로 되돌립니다.

  • 사용 통계는 동의한 경우만

    2026년 10월 27일부터, 동의한 경우에만 하루 단위로 만든 작업 수·완성 영상 수와 오류 종류를 보냅니다. 대사·파일 이름·영상은 보내지 않습니다.

  • 설치판 로그인은 선택

    계정 없이 PC에서 기본 자막 편집과 출력을 할 수 있습니다.

  • 원본 파일은 바꾸지 않음

    대본과 영상 원본은 읽기만 하고, 결과물은 따로 저장합니다.

자세한 내용은 개인정보 처리방침에 있습니다.

설치 순서

  1. 설치 파일을 받습니다(약 108MB).
  2. 'Windows의 PC 보호' 창이 뜨면 '추가 정보'를 누르고 '실행'을 누릅니다. 아직 코드 서명 인증서가 없어서 뜨는 창입니다.
  3. 처음 실행하면 인식 모델(약 1.6GB)을 내려받습니다. NVIDIA 그래픽카드가 있으면 그래픽카드 부품(약 1.4GB)도 받습니다. 인터넷 속도에 따라 몇 분 걸릴 수 있습니다.
  4. 지울 때는 Windows 설정 → 앱에서 한줄 스튜디오를 찾아 '제거'를 누릅니다. 만든 작업까지 지울지 묻고, 기본은 남겨 둡니다.

자주 묻는 질문

편집 프로그램을 처음 써도 쓸 수 있나요?

네, 처음 쓰는 분을 생각하고 만들었습니다. 대본과 영상을 넣으면 자막 문구와 시간은 한줄 스튜디오가 먼저 맞춰 둡니다. 직접 볼 곳은 시간이 애매하다고 표시된 줄뿐이고, 시즌3 5편에서는 55줄 중 8줄이었습니다. 자막 모양도 말로 고르지 않고, 실제 장면에 미리 그려 둔 4가지를 눈으로 보고 고릅니다.

무료인가요?

Windows용 시험판은 무료입니다. 웹 편집기는 하루 3편까지 무료로 편집할 수 있고, SRT 자막과 워터마크 없는 MP4를 내려받을 수 있습니다. 유료 상품별 가격과 출시 예정 기능은 웹 요금제 안내에서 확인하세요.

휴대폰에서 자막을 어떻게 만드나요?

웹 편집기에 로그인한 뒤 대본을 붙여 넣거나 파일로 선택하고 영상을 올립니다. 말소리에 맞춰 나온 초안을 확인하고 고친 뒤 완성 영상(MP4)과 자막 파일(SRT)을 내려받을 수 있습니다. Mac에서도 웹 편집기에 접속할 수 있습니다. Mac 실기기에서의 동작은 아직 확인하지 못했습니다. 설치판은 Windows용입니다.

어떤 대본 파일을 넣나요?

PDF, 텍스트(.txt), Word(.docx) 파일을 넣습니다. 파일이 없으면 대사만 한 줄씩 붙여 넣어도 됩니다. PDF는 글자를 마우스로 끌어 고를 수 있어야 하고, 종이를 스캔해 사진처럼 만든 PDF는 읽지 못합니다. 한글(.hwp)로 쓴 대본은 'PDF로 저장'해서 넣거나 대사를 복사해 붙여 넣으면 됩니다. 대본을 고르면 장면과 대사를 몇 줄 읽었는지 먼저 보여 드리고, 잘못 읽은 줄은 눌러서 고칠 수 있습니다.

대본이 없으면 쓸 수 없나요?

자막 문구를 대본에서 가져오는 방식이라 대본이 있어야 합니다. 이미 만들어 둔 자막 파일(SRT)이 있다면 첫 화면 아래 '다른 곳에서 만든 자막 파일을 영상에 넣기'로 한줄 스튜디오 모양을 입혀 영상으로 만들 수 있습니다.

어떤 영상을 넣나요?

편집을 모두 마치고 자막만 넣기 전인 완성 영상(MP4·MOV·MKV·M4V)을 넣습니다. 편집이 끝난 영상이어야 대사 시간이 맞습니다. 자막이 이미 들어간 영상이라면 넣을 때 '네, 들어 있어요'를 고르세요. 그 위에 자막을 또 입히지 않고 자막 파일(SRT)만 만듭니다. 소리가 없는 영상은 대사를 들을 수 없어서 시작하기 전에 알려 드립니다.

대본과 다르게 말한 대사는 어떻게 되나요?

대본 글과 실제로 들린 말이 많이 다르면 그 줄을 따로 표시합니다. 확인 화면에서 '들린 대로 쓰기'를 누르면 들린 말로, '글자 고치기'를 누르면 원하는 글로 바꿉니다. 편집하며 잘려서 영상에 없는 대사는 '자막에서 빼기'로 뺍니다.

Windows 설치판은 그래픽카드가 없어도 되나요?

됩니다. 그래픽카드가 없으면 CPU로 대사를 알아듣고, 시간이 더 걸립니다. 4분 영상이 NVIDIA 그래픽카드 PC에서는 약 20초, 8코어 데스크톱 CPU(AMD Ryzen 7 9700X)에서는 약 1분 걸렸습니다. 노트북처럼 CPU가 느린 PC는 더 걸립니다. 같은 편으로 한 번 비교해 보니 자막 결과는 거의 같았고, 완성 영상 파일은 Windows 기본 방식으로 만들어 약 1.2배 컸습니다.

Windows 설치판을 처음 실행할 때 왜 오래 걸리나요?

처음 한 번만 대사를 알아듣는 데 필요한 파일(약 1.6GB)을 내려받기 때문입니다. NVIDIA 그래픽카드가 있으면 그래픽카드용 부품(약 1.4GB)도 함께 받습니다. 인터넷 속도에 따라 몇 분 걸리고, 다음부터는 바로 시작합니다.

설치할 때 'Windows의 PC 보호' 창이 떠요.

아직 코드 서명 인증서가 없어서 뜨는 창입니다. '추가 정보'를 누른 뒤 '실행'을 누르면 설치가 이어집니다. 설치 파일은 이 사이트의 단추나 GitHub 공식 배포 페이지(kkoma1212/jamakfit-updates)에서만 받아 주세요.

'스마트 앱 컨트롤'이 막았다며 설치가 안 돼요.

Windows 11을 새로 설치한 PC에는 '스마트 앱 컨트롤'이 켜져 있을 수 있습니다. 이 기능은 코드 서명 인증서가 없는 프로그램을 막는데, 한줄 스튜디오는 아직 인증서가 없어서 설치도 실행도 되지 않습니다. 'Windows의 PC 보호' 창과 달리 '실행'으로 넘어갈 수 없습니다. 이런 PC에서는 사이트에 로그인해 브라우저로 써 주세요. 켜져 있는지는 Windows 보안 → 앱 및 브라우저 컨트롤에서 볼 수 있습니다.

웹 편집기는 하루에 얼마나 쓸 수 있나요?

무료 회원은 하루 3편, 한 편에 20분까지 작업할 수 있고 작업을 7일간 보관합니다. 이용 중인 요금제의 편수와 보관 기간은 웹 요금제에서 확인할 수 있습니다. 실제 처리 시간은 영상 길이와 서버의 대기 작업에 따라 달라집니다.

영상은 어디에서 처리하나요?

웹 편집기에 올린 대본과 영상은 한줄 스튜디오 서버에서 처리합니다. Windows 설치판은 대사 인식과 자막 출력을 사용자 PC에서 하며 작업 파일도 PC의 작업 폴더에 저장합니다.

로그인해야 하나요?

웹 편집기는 회원으로 로그인해 사용합니다. Windows 설치판에서는 로그인 없이 기본 자막 편집과 출력을 할 수 있습니다. 비밀번호를 잊었다면 로그인 화면의 '비밀번호를 잊었나요?'에서 메일로 받은 번호로 새로 정할 수 있습니다.

CapCut 같은 다른 프로그램에서 이어서 고칠 수 있나요?

네. 완성 화면의 'CapCut에서 더 고치려면 자막 파일만 받기'로 자막 파일(SRT)을 받아 불러오면 됩니다. CapCut PC에서는 '캡션 → 캡션 추가 → 파일 가져오기'(버전에 따라 '텍스트 → 로컬 캡션')로 불러옵니다. 자막 시간은 그대로 들어가고, 글꼴과 모양은 그 프로그램에서 다시 고릅니다.

본편을 잘라 쇼츠로 만들 수 있나요?

웹 요금제에는 긴 자막 영상의 구간을 골라 세로 쇼츠로 다듬는 Pro·Team 기능이 안내되어 있습니다. 자세한 내용은 웹 요금제에서 확인하세요. Windows 설치판은 인터뷰 대본과 인물별 장면 클립으로 질문 자막과 구역 카드를 넣은 세로 쇼츠를 만듭니다.

새 판은 어떻게 받나요?

따로 할 일은 없습니다. 한줄 스튜디오를 켤 때 새 판이 있는지 확인해 받아 두고, 다음에 켤 때 바뀝니다. 전자 서명이 맞는 파일만 쓰고, 새 판이 제대로 켜지지 않으면 이전 판으로 돌아갑니다. 만들어 둔 작업은 그대로입니다. 드물게 큰 변경이 있을 때는 새 설치 파일을 받으라는 안내가 뜹니다.

지우려면 어떻게 하나요?

Windows 설정 → 앱에서 한줄 스튜디오를 찾아 '제거'를 누릅니다. 만든 작업까지 지울지 묻고, 기본은 남겨 둡니다.
